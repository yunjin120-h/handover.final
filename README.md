# 🏢 업무 인수인계 통합 지원 시스템 (AI Edition)

> 형식이 제각각인 엑셀·회의록·메일·메모를 **AI가 읽고 이해해**,
> 후임자가 **근거와 함께 업무를 파악**하고 **첫 1~2주 온보딩 일정**과 **표준 인수인계서**까지 바로 받을 수 있게 돕는 시스템입니다.

- **체험 링크**: https://여기에-앱-주소.streamlit.app
- **시연 영상**: 여기에 영상 링크
- **팀**: 여기에 팀명 / 팀원

---

## 1. 해결하려는 문제

| 기존 인수인계 | 이 시스템을 쓰면 |
|---|---|
| 문서 전달·구두 설명 위주, 사람마다 방식이 다름 | 표준 양식의 인수인계서를 자동으로 작성 |
| 모르는 게 생기면 인계자에게 계속 추가 질문 | 궁금한 것을 바로 묻고 근거(파일·행)까지 확인 |
| 자료가 흩어져 있어 파악에 시간이 오래 걸림 | 대시보드와 온보딩 일과표로 첫 주 할 일을 바로 정리 |
| 인계자 부재·누락으로 업무 공백 발생 | 준비도 점검으로 빠진 항목을 미리 확인 |

---

## 2. 주요 기능

| 화면 | 설명 |
|---|---|
| 🏠 **대시보드** | 긴급 업무, 가장 가까운 마감, 프로젝트 진행률, 미해결 이슈, 남은 계정·자산 인계를 한 화면에 표시 |
| 📂 **Excel 업무자료** | 파일 이름·열 이름이 달라도 AI가 내용을 보고 업무일정·프로젝트·연락망·계정자산 표로 자동 분류 |
| 💬 **후임자 Q&A** | 질문에 AI가 답하고, 답변 근거가 된 **파일·시트·행 번호**를 함께 표시 |
| 📅 **온보딩 일과표** | 업무자료와 회의록·캘린더·메일에서 일정·마감·후속 조치를 뽑아 1·2주차 일과표 자동 설계. 신입/선임자가 칸을 직접 수정 가능 |
| 🤖 **인수인계서 자동 생성** | 자유 형식 업무메모 또는 올린 자료 전체를 종합해 인수인계서 초안 작성 → 검토·수정 → 준비도 점검 → Word(.docx) 다운로드 |
| ✍️ **직접 작성** | AI 없이 양식에 직접 입력해 인수인계서 생성 |
| ⚠️ **오류 자동 감지·신고** | 오류나 응답 지연을 자동으로 감지해 화면·입력·최근 동작을 담은 신고서를 자동 작성, 관리자 오류함에서 확인 |

## 3. 사용 방법 (3분 체험)

1. 체험 링크 접속
2. **📂 Excel 업무자료** 탭에 `sample_data` 폴더의 엑셀 4개(`01~04`) 업로드
3. **📅 온보딩 일과표** 탭 위쪽 칸에 회의록·캘린더·메일 문서(`.docx`)를 한 번에 업로드
4. **🏠 대시보드** → **💬 후임자 Q&A**(예시 질문 선택 후 "질문하기") → **📅 온보딩 일과표** 순서로 확인
5. **🤖 인수인계서 자동 생성**에서 `인수인계메모_김민준.txt`를 올리거나 "업로드한 전체 자료로 만들기" 선택 → Word 다운로드

> 처음 올린 자료는 AI가 분석하느라 20~60초 걸릴 수 있습니다. 같은 자료는 다시 분석하지 않아 바로 열립니다.

---

## 4. 이렇게 설계했습니다

- **어떤 형식이든 읽기**: AI가 표의 제목 행·열 이름을 보고 표준 구조로 연결합니다. 숫자·날짜 같은 실제 값은 AI가 다시 쓰지 않고 원본을 그대로 사용해 값이 바뀔 위험이 없습니다.
- **근거를 지어낼 수 없는 Q&A**: 모든 행과 문서에 번호표(ID)를 붙여 AI에 전달하고, AI는 사용한 번호표만 알려줍니다. 실제 파일명과 행 번호는 시스템이 원본에서 직접 계산합니다.
- **정해진 형식으로만 답하게**: AI 응답을 JSON 형식으로 강제해, 결과가 항상 기존 화면과 Word 양식에 맞게 들어갑니다.
- **비용 절약**: 같은 자료·같은 질문은 결과를 저장해 두고 다시 호출하지 않습니다.
- **안정성**: AI 호출이 실패하면 기존 규칙 기반 방식으로 자동 전환하고, 오류는 자동으로 기록됩니다.
- **보안**: API 키와 주민등록번호 형태의 값은 오류 신고 시 자동으로 가립니다.

## 5. 기술 스택

- **Frontend / App**: Streamlit
- **AI**: OpenAI API (기본 모델 `gpt-5.6-terra`, 설정으로 변경 가능)
- **문서 처리**: pandas, openpyxl, python-docx, pypdf
- **일과표**: HTML / JavaScript (Streamlit 컴포넌트)

---

## 6. 파일 구성

```
├── app.py              # 화면 전체 (Streamlit)
├── ai_engine.py        # AI 기능: 파일 읽기, 표 인식, Q&A, 일정 추출, 인수인계서 생성
├── memo_parser.py      # AI 연결 실패 시 사용하는 업무메모 규칙 기반 분석
├── qa_engine.py        # AI 연결 실패 시 사용하는 Q&A 규칙 기반 검색
├── requirements.txt    # 필요한 라이브러리
├── .streamlit/
│   └── config.toml     # 화면 테마 설정
└── sample_data/        # 체험용 가상 데이터 (엑셀 4개, 회의록·메일·캘린더, 인계메모)
```

---

## 7. 직접 실행하기

```bash
pip install -r requirements.txt
```

`.streamlit/secrets.toml` 파일을 만들고 OpenAI API 키를 넣습니다. (이 파일은 저장소에 올리지 마세요)

```toml
OPENAI_API_KEY = "sk-..."
```

```bash
streamlit run app.py
```

## 8. 한계와 향후 계획

- 온보딩 일과표에서 수정한 내용은 현재 화면에서만 유지되며, 저장·내보내기 기능은 추가 예정입니다.
- 오류 신고 기록은 현재 로컬 파일에 저장되며, 운영 환경에서는 데이터베이스 연동으로 확장할 수 있습니다.
- 사내 메일·캘린더 시스템과 직접 연동해 자료를 자동으로 가져오는 방향으로 확장할 수 있습니다.
